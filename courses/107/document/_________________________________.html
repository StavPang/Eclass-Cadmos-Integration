Ας δημιουργήσουμε

Οι μαθητές καλούνται να αναδείξουν τη δημιουργική τους σκέψη φτιάχνοντας ένα βίντεο animation όπου θα δίνουν οδηγίες σε άλλα παιδιά ίδιας ή μικρότερης ηλικίας σχετικά με το: πώς μπορούμε να σώσουμε τη Γη?

Learning Goals:

  • • να διατυπώνουν την αξία και τα οφέλη της ανακύκλωσης συσκευασιών
  • • να ξεχωρίζουν ποιες συσκευασίες ανακυκλώνονται
  • • να συνδέουν τα ανακυκλώσιμα υλικά με καθημερινά προϊόντα
  • • να διαχωρίζουν τα υλικά, που μπαίνουν στον μπλε κάδο

Activity Details:

Activity Type: Creating
Target Audience: Pair Group
Facilitator: Teacher
Facilitator Role: Tutor
