Python Basics Flashback

In this activity students will participate in a flashback session designed to stimulate the recall of any existing knowledge they may have about Python and programming. The session will begin with a brief overview of key Python concepts such as variables loops and conditionals. Students will then engage in a group brainstorming exercise where they list any programmingrelated terms or concepts they are familiar with regardless of their source. Following this students will pair up and share anecdotes or experiences where they encountered programming whether in previous courses workshops or personal projects. Each pair will present one shared experience to the class allowing for a diverse range of prior knowledge to be brought to the surface. This reflective exercise aims to tap into learners existing cognitive frameworks making it easier to build new knowledge upon them

Learning Goals:

  • Identify basic Python syntax and key programming concepts such as variables loops and conditionals

Activity Details:

Activity Type: Remembering
Target Audience: Group
