Code Debugging Workshop

This workshop involves students working in pairs to examine and debug Python code identifying common errors and inefficiencies and discussing strategies to optimize the code.

Learning Goals:

  • Examine and debug Python code to identify common errors and inefficiencies

Activity Details:

Activity Type: Analyzing
Target Audience: Student
Facilitator: Teacher
Facilitator Role: The Teacher supports the learners by guiding them through the debugging process providing feedback on their strategies
